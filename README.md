# Igarabit - Home MVP

Bem-vindo ao repositório do MVP (Minimum Viable Product) da página inicial do **Igarabit**! 

O Igarabit é uma plataforma dedicada a **Música, Arte e Cultura do Norte** do Brasil. Este projeto é a interface inicial onde artistas e o público podem descobrir eventos, encontrar criadores locais e fazer parte da maior comunidade cultural da Amazônia.

## 🎨 Sobre o Projeto

Este repositório contém a página de apresentação (Landing Page) desenvolvida com:
- **HTML5** estruturado
- **CSS3** nativo (Vanilla CSS), seguindo uma identidade visual marcante
- Padrões visuais regionais com foco em coletividade e vozes do Norte
- Tipografia moderna e animações interativas suaves

## 🚀 Como Executar Localmente

Como o projeto é estático e não requer processos de build complexos, é muito fácil rodar localmente:

1. Clone o repositório para sua máquina:
   ```bash
   git clone https://github.com/maktheus/igarabit-home-mvp.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd igarabit-home-mvp
   ```
3. Abra o arquivo `index.html` diretamente em seu navegador web (Google Chrome, Firefox, Safari, etc.) ou utilize a extensão *Live Server* do VS Code para uma melhor experiência de desenvolvimento.

## 🌐 Deploy no GitHub Pages

Este projeto está pronto para ser hospedado gratuitamente no **GitHub Pages**. Para ativá-lo:

1. Vá até a aba **Settings** (Configurações) deste repositório no GitHub.
2. No menu esquerdo, clique em **Pages**.
3. Em "Source", selecione a opção **Deploy from a branch**.
4. Na seção "Branch", selecione **`master`** e a pasta **`/(root)`**.
5. Clique em **Save**.
6. Em alguns minutos, seu site estará no ar e um link será gerado pelo GitHub!
